# bytebeat

write a track in the browser, ship it, and get a byte-sized snack from [hack club](https://hackclub.com).

check it out at [bytebeat.hackclub.com](https://bytebeat.hackclub.com).

## what's here

- **[guide](https://bytebeat.hackclub.com/guide)**: da guide
- **[editor](https://bytebeat.hackclub.com/editor)**: a unique editor for rendering and sharing songs!
- **[references](https://bytebeat.hackclub.com/references)**: some references

## built with
[sveltekit](https://svelte.dev/docs/kit), [svelte 5](https://svelte.dev), [drizzle](https://orm.drizzle.team) and [postgres](https://www.postgresql.org). 

run by ck and jared.
